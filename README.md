**Student Hostel Booking Mobile App**

**Project Description**

The Student Hostel Booking Mobile App is an HCI prototype designed to help university students find and book suitable accommodation. The application allows students to view available hostels and rooms, compare room options, select a room, confirm a booking, and view booking and payment status.

**HCI Focus**

The prototype focuses on:

- Mobile task flows
- Form design
- Feedback
- Error prevention
- Visual hierarchy
- Consistent navigation
- User-friendly interaction

**Main Features**

- View available hostels and rooms
- Compare room options
- Select a room
- Enter booking details
- Confirm a booking
- Make a payment
- View booking status
- View payment status

**User Task Flow**

Login → Home → View Hostel → View Rooms → Compare Rooms → Select Room → Booking Details → Confirm Booking → Payment → Booking & Payment Status

**Prototype Screens**

The prototype consists of multiple screens representing the student's accommodation booking journey.

**Screen 10 – Booking Confirmation**

Screen 10 allows the student to review their selected accommodation and booking details before confirming the booking.

The screen provides:

- Selected hostel
- Selected room
- Room type
- Booking duration
- Amount to be paid
- Terms and conditions
- Confirm Booking button
- Option to go back and make changes

This screen supports error prevention by allowing the student to review their information before completing the booking.

**Screen 11 – Booking and Payment Status**

Screen 11 provides feedback after the booking and payment process.

The screen displays:

- Booking confirmation
- Booking reference number
- Selected hostel and room
- Payment status
- Booking status
- Option to view the booking
- Option to return to the home screen

This screen focuses on feedback and visibility of system status, allowing the student to clearly understand whether their booking and payment were successful.

**HCI Principles Demonstrated**

HCI Principle | Application
|---|---|
|Mobile task flows| Guides the student through the accommodation booking process|
|Form design| Organizes booking and payment information clearly|
|Feedback| Displays confirmation and payment status|
|Error prevention| Allows users to review details before confirming|
|Visual hierarchy| Important information and actions are clearly emphasized|
|Consistency| Uses consistent navigation and interaction elements|
|Visibility of system status| Shows booking and payment progress/results|

**Prototype Tool**

The prototype was designed using Balsamiq.

**Project Purpose**

The purpose of this project is to demonstrate HCI principles by designing a simple, intuitive, and efficient mobile application for university accommodation booking.
