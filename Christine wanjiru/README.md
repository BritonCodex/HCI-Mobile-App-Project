# DeKUT Hostel Connect

## Objectives

The main objectives of the prototype are to:

* Enable students to view available hostels and rooms.
* Allow students to view hostel details, prices, and amenities.
* Enable students to compare different room options.
* Allow students to select and confirm a room booking.
* Enable students to view their booking and payment status.
* Provide students with check-in information and a QR code.
* Provide access to a digital booking receipt.

## Main Features

The prototype includes the following features:

* Hostel browsing
* Hostel details and amenities
* Room comparison
* Room selection
* Booking confirmation
* Booking details
* Payment status
* QR-code check-in
* Receipt download
* Bottom navigation
* Back navigation

## Prototype Screens

### Screen 3 – Hostel Details

The Hostel Details screen provides students with information about a selected hostel, including:

* Hostel image
* Hostel name
* Monthly price range
* Hostel description
* Available amenities
* Compare Rooms option
* View Available Rooms button
* Back navigation
* Bottom navigation

### Screen 12 – Booking Details / Check-in Status

The Booking Details screen provides students with information about their confirmed booking and check-in process. It includes:

* Booking information
* Hostel and room details
* Check-in and check-out dates
* QR code for check-in
* Check-in instructions
* Download Receipt button
* Bottom navigation

## Navigation

The application uses a simple bottom navigation structure to help users move between the main sections of the application:

* Home
* Search
* Bookings
* Profile

A back button is also provided on detailed screens to allow users to return to the previous screen.

## HCI Principles Applied

The prototype applies several Human-Computer Interaction principles, including:

### Visual Hierarchy

Important information such as hostel names, prices, amenities, and action buttons is given clear visual prominence.

### Consistency

The same navigation structure, typography, spacing, and interface elements are used across screens.

### User Control

Users can navigate back, compare rooms, view available rooms, and access their booking information.

### Feedback

Booking confirmation and check-in information provide users with feedback about the status of their booking.

### Error Prevention

Clear labels, structured information, and straightforward actions help reduce user errors during the hostel booking process.

### Ease of Use

The interface is designed for mobile users with simple navigation, readable information, and clearly labeled buttons.

## Conclusion

DeKUT Hostel Connect demonstrates the design of a mobile hostel booking application that focuses on usability, clear navigation, visual hierarchy, feedback, and error prevention. The prototype provides a simple task flow that guides students from viewing hostel information to selecting accommodation and accessing their booking and check-in details.
